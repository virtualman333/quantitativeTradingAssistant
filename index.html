多专家并行

LangGraph 扇出并行给观点，主 Agent 汇总冲突后拍板；专家定义外置，增删专家 = 增删目录。

🛡️

L1 硬约束在代码里

杠杆上限、止损、仓位红线由类型与执行层守住，不交给模型自由裁量；月度回撤熔断（≥12% 停新仓）主 Agent 与超短线循环共用同一道闸门。「这笔有没有止损」的判据只有一份，且只认带止损触发价的委托 —— 一条只有止盈的单不算止损；裸仓按每笔持仓逐笔巡检，不是只看账户里有没有挂单。

📊

超短线策略库

内置 + 自定义策略，支持多周期批量回测：胜率 / 盈亏比 / 期望 / 最大回撤，规则单与 LLM 单分开对比。

🕶️

提示词混淆层

发给模型提供方之前先混淆，降低策略与上下文被记录的风险。

🖥️

桌面端多窗口

Electron + Vue3：行情 / 持仓 / 日志 / 报告 / 回测 / 设置，各自独立窗口。
