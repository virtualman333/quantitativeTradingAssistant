# 市场情绪与持仓结构专家 · 领域经验

## 持仓量（OI）与量价
- OI 揭示持仓动态与趋势强度：价格新高 + OI 上升 = 新增资金推动（趋势健康）；
  价格新高 + OI 下降 = 空头平仓驱动（动能存疑）。
- 价格新低 + OI 上升 = 新增空头（趋势可能延续）；价格新低 + OI 下降 = 多头止损离场（或接近尾声）。

## 多空比与情绪极值
- 多空比极端（一面倒）是反向参考：极度贪婪时警惕回调，极度恐慌时关注超跌反弹机会。
- 情绪指标是「温度计」不是「方向盘」：极值做反向参考，不单独构成信号。

## 量价背离
- 价格创新高但量能/OI 不配合 = 背离，动能衰减；价格创新低但抛压萎缩 = 底部特征之一。
- 背离要与资金费率、链上流量交叉验证，单一背离容易误判。
