# 聪明钱与信号解读（来源：okx-cex-smartmoney skill，@okx）

OKX 聪明钱数据的解读框架：交易员排行、持仓跟踪、聚合共识信号。
（本知识来自 SkillForge 投资分类下 okx-cex-smartmoney skill，已精炼为要点）

## 信号维度
- 交易员排行（leaderboard）：顶尖交易员的持仓、交易记录、收益
- 聚合共识信号（consensus signal）：单一币种多聪明钱交易员的共识方向
- 信号历史（signal history）：共识信号的时间线，用于趋势分析

## 解读要点
- 聪明钱共识信号 = 顶尖交易员的聚合方向，可作为情绪/资金流向的辅助验证
- 信号历史趋势比单点快照更有意义：关注共识方向的一致性与变化方向
- 多空比（long/short ratio）与仓位强度（position conviction）结合看
- 交易员完整画像（持仓 + 交易记录 + 收益）优先于单一排行数值

## 与项目结合
- 本项目 OKX MCP 目前无聪明钱 API；如需接入需额外开通 OKX 聪明钱数据权限
- 信号只作辅助验证，不作为独立开仓依据（与章程一致：方向由 factor/trading 主导）

## 全局纪律
- 永远不要在聊天中要求粘贴 API 密钥/私钥
- 只读信号不改变仓位管理 / 止损纪律（L1 硬约束优先）
