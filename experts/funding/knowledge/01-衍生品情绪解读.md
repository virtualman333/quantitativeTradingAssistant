# 衍生品情绪解读（来源：coinglass skill，@starchild-ai-agent）

补充资金费率分档、持仓量×价格矩阵、多空比、清算、CVD 等解读阈值。
（本知识来自 SkillForge 投资分类下 coinglass skill 的解读指南，已精炼为要点）

## 资金费率精确分档（8h）
- > +0.05%：极度贪婪，多头拥挤，存在挤压（squeeze）风险
- +0.01% ~ +0.05%：看涨倾向，正常
- -0.005% ~ +0.01%：中性
- -0.05% ~ -0.005%：看跌倾向，正常
- < -0.05%：极度恐惧，空头拥挤，存在反弹（轧空）风险
- 极端费率往往预示反转：极端时大众通常是错的。

## 持仓量 OI × 价格矩阵
- OI 升 + 价升 = 新多头入场，看涨信心足
- OI 升 + 价降 = 新空头入场，看跌信心足
- OI 降 + 价升 = 空头回补，反弹较弱（信心不足）
- OI 降 + 价降 = 多头清算，抛售较弱（投降式抛售）

## 多空比（long/short ratio）
- > 1.5：多头拥挤，逆向看跌
- 1.1 ~ 1.5：适度看涨
- 0.9 ~ 1.1：均衡
- 0.7 ~ 0.9：适度看跌
- < 0.7：空头拥挤，逆向看涨

## 聪明钱 vs 散户
- 顶级账户多空比（聪明钱）vs 全球账户多空比（散户）背离 = 方向信号，两者反向时跟随聪明钱
- 顶级仓位/账户规模分布反映主力动向，散户情绪常是反向指标

## 清算数据
- 清算密集区（清算热力图）是潜在支撑/阻力位与波动放大点
- 大额单笔清算常出现在关键位附近，警惕清算级联（cascade）风险

## CVD（累计成交量差 = 主动买 - 主动卖）
- CVD 升 + 价升 = 强劲买压，健康上涨
- CVD 降 + 价升 = 弱势反弹，派发中
- CVD 升 + 价降 = 吸筹中，可能见底
- CVD 降 + 价降 = 强劲卖压，健康下跌

## 分析模式
- 多指标确认：资金费率 + 多空比 + 清算 = 仓位极端；CVD + 主动量 + 鲸鱼 = 聪明钱方向
- 极端费率 + 高 OI + 多空比极端 = 反向风险最高的组合
