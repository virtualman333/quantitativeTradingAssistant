## 策略库内置常用策略 + 分类 + 显示优化（提交 45be11c，已 push）
- 内置 7 个：sample-trend 斜率顺势、双均线趋势跟随、MACD 趋势跟随（趋势跟踪）；布林带回归、RSI 超买超卖反转（均值回归）；唐奇安通道突破、放量突破（突破通道）。每个含 meta.builtin=true，文件已入库。
- 机制：`BUILTIN_STRATEGIES`（TS 内）为唯一事实源；`ensureBuiltins()` 比对磁盘 strategy.py/meta.json（strategy.py 用 trimEnd 比对，避免行尾换行差异导致每次 IPC 反复重写）不一致才还原；electron `loadStrategies()`（main.ts）每次加载前调用。内置不可删除（deleteStrategy 抛错）、不可覆盖（saveStrategy 遇 builtin 强制按名称 ensureIdExists 另存）。
- meta.json 新增 `category`（趋势跟踪/均值回归/突破通道/自定义）；readMeta 读侧兜底（旧数据内置→趋势跟踪、其余→自定义），列表 listStrategies 内置优先（按 BUILTIN 顺序）再按 updatedAt。
- UI BacktestView：分类 chips 筛选（filterCat + catCounts）+ 按分类 tbody v-for 分组（组标题行 cat-row）；策略名徽标 引擎内置(t-hold)/内置(t-info)/我的(t-buy)；引擎默认规则并入趋势跟踪组作 ENGINE_ENTRY(id:'')；内置行仅「复制为自定义」（openCopyStrategy → mode copy 名称自动加「副本」预填代码/元数据另存）；编辑弹窗新增分类下拉。
- 教训：Vue 表格里想给 tbody v-for 分组，直接 `<tbody v-for>` 即可；误用 `<template v-for>` 包 tbody 时把 `<td colspan>` 行误删过——同文件内连续 edit 别贪多，宁可多读一次。
