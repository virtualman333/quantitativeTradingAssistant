## 批量回测多进程并行
用户需求：涉及批量回测支持多线程回测。
- Python `scalper_backtest.py` `_db()`：`isolation_level=None`（autocommit）+ `PRAGMA journal_mode=WAL` + `busy_timeout=30000`，新增 `_tx()` 用 `BEGIN IMMEDIATE`…COMMIT/ROLLBACK 包单批写入（`_write_1m`/`_agg_bucket` 改用它）→ 多进程并发写缓存不再有「先读后写锁升级死锁 / database is locked」。
- UI `BacktestView.vue`：
  - 表单新增 `concurrency`（默认 3，持久化；chips 1~4 路），`btConcurrency()` 解析并封顶。
  - `runBatch` 串行 for 循环 → worker 池（`Promise.all` N 个 worker 领号跑格，`live[key]` 天然 keyed 支持多格同跑）；行内/矩阵「运行中 xx%」本来就是按 key 独立显示，天然适配并行。
  - 批量进度条改为总体估算：完成数 + 各进行中格的实时 p 累加；bt-strip 头部显示「完成/总数 · N 路并行中」，下面逐条列出各进行中格名称+百分比。
  - 「停止后续」语义不变：正在跑的格跑完即止，不再领新格。
- main.ts 无需改（每个 job 独立 spawn/rec/Map/广播，本来就并发安全）。

验证：`pnpm run build` 通过；3 个进程同时冷区间回测（5m/15m/1H 重叠取数与聚合写库）全部 rc=0，无锁错误。
