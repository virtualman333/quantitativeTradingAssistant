## git 仓库根迁移 + 首个 Release
- 需求：让 `agent/`（当前工作目录）成为 git 主目录，并发布 release。
- 做法：父仓库（原根 `OKX Trader\`，所有文件带 `agent/` 前缀）先提交待改 → 建 `backup/agent-prefix` 分支并推送（旧历史备份）→ `git subtree split --prefix=agent -b agent-root` 重写历史 → 在 `agent/` 里 `git init` + `fetch .. agent-root` + `reset --hard FETCH_HEAD` 接管历史 → 补 `.gitignore` → 强推 `main`。
- 远程几经改名，最终为 `https://github.com/virtualman333/quantitativeTradingAssistant.git`（`git remote set-url` 已同步）。push 时 GitHub 会提示 "repository moved"，以提示的新地址为准。
- Release：本机无 gh CLI，改用 `git credential fill < 输入文件`（写 `protocol=https\nhost=github.com\n\n`）从 Windows 凭据管理器取 PAT，再 `Invoke-RestMethod` POST `/repos/{owner}/{repo}/releases` 创建。tag `v0.1.0` 已推送，Release 地址 `/releases/tag/v0.1.0`。用完即删临时文件（含 token）。
- 注意：父目录 `OKX Trader\.git` 因被占用（Access denied）未能改名，仍在；不影响 agent 仓库，可手动删除（旧历史已在 `backup/agent-prefix` 分支）。
- 坑：本工具里 `cd /d ... ; powershell ...` 混写会让整行被 PowerShell 解析（`cd /d` 报错且 cwd 变成工作目录）→ 需要 PS 时整条命令都写成 `powershell -NoProfile -Command/-File`，并用绝对路径；不要在混写命令里做重命名（曾误把 agent/.git 改名）。
