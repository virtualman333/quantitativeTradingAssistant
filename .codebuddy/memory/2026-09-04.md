# 2026-09-04

## 热门行情点击进新窗口显示首页 bug 修复
- 现象：点击「热门行情」交易对，新开窗口显示的是首页而非 K 线图。
- 根因：`electron/main.ts` 的 `loadUi()` dev 分支原来 `w.loadURL(devUrl + (hash ? "#" + hash : ""))`，而 `nav.js` 传的 hash 已带 `#`（形如 `#/win/kline?instId=xxx`），于是拼成 `##/win/kline?...` 双 `#` → `location.hash` 解析失败 → `parseRoute` 返回 null → `winRoute=null` → 独立窗口退化成渲染主界面（首页）。
- 修复：`loadUi` 统一先 `hash.replace(/^#/,"")` 去掉 #，各加载方式再自行加 #（dev 用 `devUrl + "#" + h`，dist 用 `loadFile(..., {hash: h})`）。dist 分支原逻辑本就正确（`hash.replace(/^#/,"")`），本次统一后两种模式都 robust。
- 复用窗口分支（`executeJavaScript("location.hash = ...")`）本就正确，未动。
- 独立窗口路由链路：nav.js `openKlineWin` → `#/win/kline?instId=...` → 主进程 `win:open` → `loadUi(w, hash)` → App.vue 按 `winRoute` 渲染 WinFrame。关键：hash 全程保持「带 # 一次」，不能在 loadURL 时二次加 #。
