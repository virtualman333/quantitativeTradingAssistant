# 2026-09-03 工作记录

## Electron 顶层菜单中文化（agent/electron/main.ts）
- 原状：未设置菜单，走 Electron 默认英文菜单（File / Edit / View / Window / Help），右键菜单也是英文。
- 新增 `buildMenu()`：文件 / 编辑 / 视图 / 窗口 / 帮助 五组全中文；macOS 额外加首项「应用名」菜单（关于 / 服务 / 隐藏 / 隐藏其他 / 显示全部 / 退出）。
- 关键点：**`role` 只负责行为，不负责翻译**，label 必须逐个写中文，否则仍显示英文。
- `app.name = "OKX 交易 Agent"` 必须在 app ready 前设置，macOS 菜单首项与「关于」才会用到它。
- 新增 `attachContextMenu(win)`：右键菜单的中文化（剪切/复制/粘贴/全选/检查元素），用 `params.editFlags` 控制可用状态。
- 文件菜单里接了实际动作：启动服务(CmdOrCtrl+Shift+S)、停止服务(Shift+X)、跑一轮决策(Shift+O)、打开数据文件(Shift+D)、打开 state / logs 目录。

## 顺带修掉的隐患
- `runOnceAgent()`（原 `agent:runOnce` 内联逻辑）原先判断 `st?.dryRun ? ["--dry-run"] : []`：设置缺失时会**不带演练标志直接跑一轮**（可能下真实单）。改为 `!== false`（默认演练），与 `startAgent()` 行为一致。该函数已抽出，界面按钮与顶层菜单共用。
