- 原状：未设置菜单，走 Electron 默认英文菜单（File / Edit / View / Window / Help），右键菜单也是英文。

## 修复「模型调用失败(Hy3-CodeBuddy)」HTTP 400 / 11101（src/llm.ts）
- 现象：专家全部 abstain，界面提示 `模型调用失败(Hy3-CodeBuddy): ... code 11101 Non-stream chat request is currently not supported`。报错文案出自 `graph.ts:100`（decide 异常被吞成 abstain）。
- 根因：`OpenAICompatProvider.decide()` 发的是**非流式**请求；而 `copilot.tencent.com/v2` 网关只支持流式。对话页走 `streamChat`（流式）因此正常 —— 这就是「对话能用、跑一轮/测试连接失败」的原因。
- 修复：decide() 遇到 400 且响应体匹配 `non-?stream|11101|only stream|只支持流式` 时，把模型 id 记入模块级 `streamOnlyModels` Set，改走 `openaiChat` 流式拼接结果，调用方（专家/调度/主 Agent/testModel）无感知；非该类错误（鉴权、参数）仍原样抛出，不掩盖真实问题。
- 未做验证：联网实测未跑成（tsx --eval 相对路径解析失败，且用户取消了命令）；`tsc -p tsconfig.json --noEmit` 已通过。建议用界面「测试连接」确认。
- 附：当前默认模型是 store.json（已 gitignore）里的 `Hy3-CodeBuddy`（`https://copilot.tencent.com/v2`，model `hy3`），Key 也在该文件里，勿外泄。
